  1. GLOSSARY AUTO-LINKING (1,526 internal links)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: Blog posts had zero internal links to glossary terms. Every page
was an SEO island — link equity didn't flow between pages.

Fix: Created scripts/add-glossary-links.mjs and scripts/add-glossary-links-dist.mjs
that process ALL static HTML blog files to inject glossary term links.

How it works:
  - Reads each .html file in public/blog/ and dist/blog/
  - Protects existing <a> tags (doesn't re-link already-linked text)
  - Matches 50+ glossary terms using word-boundary regex (case-insensitive)
  - Wraps matches in <a href="/glossary/{slug}" class="glossary-link"> tags
  - Restores protected existing links

Results:
  - public/blog/: 38 files, 1,526 glossary links
  - dist/blog/: 34 files, 1,342 glossary links
  - youtube-tags-2026 page: 31 glossary links
  - what-does-youtube-ctr-actually-mean: 54 glossary links
  - youtube-analytics-explained-2026: 155 glossary links
