## Style Prompt
Cyber-Luxe Dark — premium SaaS aesthetic with electric cyan and acid green on deep midnight backgrounds. Glass morphism, sharp geometry, geist typography.

## Colors
- **Primary / Electric Cyan**: `#00f2ff` — CTAs, highlights, active states
- **Accent / Acid Green**: `#00ff88` — success, scores, positive metrics
- **Background / Midnight Navy Deep**: `#0a0b10` — page background
- **OLED Black**: `#000000` — deepest blacks
- **Card Glass**: `rgba(16, 20, 32, 0.6)` — cards, panels
- **Text Active**: `#ffffff` — headings, active nav
- **Text Primary**: `#f0f2f5` — body text
- **Text Muted**: `#a8b2c1` — secondary text
- **Danger**: `#ff3366` — errors, warnings

## Typography
- **Primary**: Geist (sans-serif) — body, headings, UI
- **Mono**: Geist Mono, Fira Code — code, data, metrics
- **Fallback**: Outfit, sans-serif

## Motion
- Sharp, precise, cyberpunk-adjacent
- Cubic-bezier(0.23, 1, 0.32, 1) for card animations
- Glow pulses on primary elements
- Border glow on hover states
- No bouncy/playful easing — clean and technical

## What NOT to Do
- NO purple, violet, or indigo anywhere (explicitly banned in project CSS)
- NO rounded/bubbly UI — sharp geometry (radius ≤ 1rem)
- NO warm/orange tones
- NO serif fonts
- NO bouncy/spring animations — keep it precise
