### What it does

YouTube processes 3.7 million new videos daily. Most never get seen — not because the content is bad, but because the metadata isn't optimized for search and recommendations.

YT SEO Architect analyzes your channel and gives you specific fixes:

- **Tag Generator** — AI-powered keyword suggestions with competition scores
- **Title Optimizer** — Generates and scores title variations for CTR
- **Description Writer** — SEO-optimized templates with keyword placement
- **Thumbnail A/B Testing Guide** — Data-backed testing framework
- **Analytics Dashboard** — 4-metric diagnostic for underperforming videos

### Quick start

```bash
# No install needed — web-based
open https://yt-seo-architect.vercel.app/dashboard
```
